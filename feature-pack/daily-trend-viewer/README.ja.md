# daily-trend-viewer

**YouTube · ショート · Instagram リール · X · Threads · TikTok の人気コンテンツと AI 動画ニュースを 1 画面で見るローカル Web サイト — API キーも追加パッケージも不要です。**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

</div>

> [AI Feature Pack](../../README.ja.md) のパックです。パック同士は独立しているので、必要なものだけ入れてください。

## できること

- YouTube · ショートの人気動画をカテゴリ × 期間(今日 · 今週 · 今月)で絞り込み、再生回数順または高評価順で見られます。カードをクリックするとポップアップで再生します。
- ヘッダーの検索欄で YouTube を任意のキーワードで検索し、再生回数順で表示します。
- AI 動画タブでは、新しい動画生成モデル · トレンドのモデル(Hugging Face)と国内外の AI 動画ニュース(Google ニュース RSS)を見られます。
- リール · X · Threads · TikTok タブでは、フォローしているアカウントの最新投稿を集めます。アカウントは画面で追加 · 削除できます。
- 結果は 1 時間キャッシュされ、右上の更新ボタンですぐに更新できます。
- Python 標準ライブラリだけを使います。サーバーは `127.0.0.1` でのみ待ち受けます。

## クイックスタート

```bash
# リポジトリのルートから
cd feature-pack/daily-trend-viewer/app
python3 server.py
# ブラウザで http://localhost:28088 を開く · 終了は Ctrl+C
```

## インストール

エージェントに任せるなら「`feature-pack/daily-trend-viewer/INSTALL.md` を読んでインストールして」と伝えてください。

手動の場合: Python 3.8 以上があれば十分です。`app/` フォルダーがアプリのすべてなので、好きな場所に丸ごとコピーしても、この場所でそのまま実行してもかまいません。ポート 28088 が使用中なら、`app/server.py` 冒頭の `PORT = 28088` を空いているポートに変えます。

```bash
# macOS: app/실행-Mac.command をダブルクリック(Gatekeeper の警告が出たら右クリック → 開く)、または
cd app && python3 server.py
# Windows: app\실행-Windows.bat をダブルクリック
# 確認 — 200 なら正常
curl -s -o /dev/null -w "%{http_code}" http://localhost:28088/
```

## 使い方

### タブ

| タブ | 見られるもの | 並べ替え |
|---|---|---|
| YouTube / ショート | カテゴリ(すべて · AI · モッパン · ビューティー · Vlog · バラエティ · 映画/ドラマ · テック · 知識 · 旅行 · 動物) × 期間 | 再生回数 · 高評価 |
| AI 動画 | 新しい動画生成モデル · トレンドのモデル · AI 動画ニュース(テキスト中心) | — |
| リール | フォロー中アカウントの最新リール | 再生回数 · いいね · コメント |
| X | フォロー中アカウントの最新投稿 | いいね · 返信 · リツイート |
| Threads | フォロー中アカウントの最新投稿(ブロック時はアカウントへのリンク) | いいね · 返信 · リポスト |
| TikTok | リアルタイム人気フィード(韓国) + フォロー中アカウントの最新動画 | 再生回数 · いいね · コメント |

人気の AI 動画は YouTube タブの「AI」カテゴリにあります。検索すると動画タブに切り替わり、カテゴリをクリックすると検索が解除されます。

### アカウント一覧

画面でアカウントを変更すると、`app/` に次のファイルが作られます。バックアップや移動のときは一緒にコピーしてください。

| タブ | ファイル |
|---|---|
| リール | `reels_accounts.json` |
| X | `x_accounts.json` |
| Threads | `threads_accounts.json` |
| TikTok | `tiktok_accounts.json` |

### データの出どころと制限

- YouTube: 内部検索 API(InnerTube)を再生回数順で呼びます。YouTube の公開急上昇フィードは 2025 年に廃止されたため、検索ベースで構成しています。
- リール: instagram.com の Web が使う内部 API をログインなしで呼びます。1 アカウントにつき最新 12 件までで、リクエストが多いと Instagram に一時的に制限されることがあります。サムネイルはサーバーのプロキシ(`/api/img`)経由で渡します。
- X: 埋め込みウィジェット用の syndication API をログインなしで呼びます。この API には再生回数がないため、再生回数順の並べ替えは外しています。
- Threads: 現在は既定でブロックされているため、アカウントへのリンクに切り替わります。`server.py` の `THREADS_DOC_IDS` に有効な doc_id を入れるとリアルタイム取得が動きます。
- TikTok: 無料の公開 API tikwm(`www.tikwm.com/api`)を経由します。無料枠なので、サーバーは低い同時実行数(3)で呼び、1 時間キャッシュします。

### 知っておくこと

- TikTok のリクエスト(アカウントのハンドル · 閲覧内容)は第三者サービスの tikwm.com に送られます。そのサービスが変わると、TikTok タブはいつでも止まる可能性があります。
- すべてのプラットフォームのデータは、非公式 · 認証なしの内部 API で取得しています。各サービスの規約上グレーゾーンで、予告なくブロックされることがあります。個人の閲覧用にとどめ、更新しすぎないでください。
- このパックの `server.py` には、オリジナルにはないセキュリティ修正が 2 件入っています: アカウント変更 POST の Origin 検証、画像プロキシのホスト検査の強化。

## 必要なもの

- Python 3.8 以上(標準ライブラリのみ · 追加パッケージなし)
- API キー / アカウント: なし
