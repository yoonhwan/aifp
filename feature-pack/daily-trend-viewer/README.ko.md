# daily-trend-viewer

**유튜브 · 쇼츠 · 인스타 릴스 · X · 스레드 · 틱톡 인기 콘텐츠와 AI 영상 소식을 한 화면에서 보는 로컬 웹사이트 — API 키도, 추가 패키지도 필요 없습니다.**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

> [AI Feature Pack](../../README.ko.md) 의 팩입니다. 팩은 서로 독립이라 필요한 것만 설치하면 됩니다.

## 무엇을 하나요

- 유튜브 · 쇼츠 인기 영상을 카테고리 × 기간(오늘 · 이번 주 · 이번 달)으로 걸러 조회수순 또는 좋아요순으로 봅니다. 카드를 누르면 팝업으로 재생합니다.
- 헤더의 검색창으로 유튜브를 아무 키워드로 검색해 조회수순으로 봅니다.
- AI 영상 탭에서 새로 나온 영상 생성 모델 · 트렌딩 모델(Hugging Face)과 국내 · 해외 AI 영상 뉴스(구글 뉴스 RSS)를 봅니다.
- 릴스 · X · 스레드 · 틱톡 탭에서 구독 계정의 최신 글을 모아 보고, 계정을 화면에서 추가 · 삭제합니다.
- 결과는 1시간 캐시하고, 오른쪽 위 새로고침 버튼으로 바로 갱신합니다.
- 파이썬 표준 라이브러리만 씁니다. 서버는 `127.0.0.1` 에만 열립니다.

## 빠른 시작

```bash
# 리포 루트에서
cd feature-pack/daily-trend-viewer/app
python3 server.py
# 브라우저에서 http://localhost:28088 접속 · 끝낼 때는 Ctrl+C
```

## 설치

에이전트에게 맡기려면 «`feature-pack/daily-trend-viewer/INSTALL.md` 를 읽고 설치해줘» 라고 말하세요.

손으로 할 때: Python 3.8 이상만 있으면 됩니다. `app/` 폴더가 실행 단위 전부라, 원하는 곳에 통째로 복사해도 되고 이 자리에서 바로 실행해도 됩니다. 포트 28088 이 이미 쓰이고 있으면 `app/server.py` 맨 위의 `PORT = 28088` 을 빈 포트로 바꿉니다.

```bash
# macOS: app/실행-Mac.command 더블클릭 (게이트키퍼 경고가 뜨면 우클릭 → 열기) 또는
cd app && python3 server.py
# Windows: app\실행-Windows.bat 더블클릭
# 확인 — 200 이 나오면 정상
curl -s -o /dev/null -w "%{http_code}" http://localhost:28088/
```

## 사용법

### 탭

| 탭 | 보는 것 | 정렬 |
|---|---|---|
| 유튜브 / 쇼츠 | 카테고리(전체 · AI · 먹방 · 뷰티 · 브이로그 · 예능 · 영화/드라마 · 테크 · 지식 · 여행 · 동물) × 기간 | 조회수 · 좋아요 |
| AI 영상 | 새 영상 생성 모델 · 트렌딩 모델 · AI 영상 뉴스(글 중심) | — |
| 릴스 | 구독 계정의 최신 릴스 | 조회수 · 좋아요 · 댓글 |
| X | 구독 계정의 최신 글 | 좋아요 · 댓글 · 리트윗 |
| 스레드 | 구독 계정의 최신 글(막혀 있으면 계정 바로가기) | 좋아요 · 댓글 · 리포스트 |
| 틱톡 | 실시간 인기 피드(한국) + 구독 계정의 최신 영상 | 조회수 · 좋아요 · 댓글 |

인기 AI 영상은 유튜브 탭의 «AI» 카테고리에 있습니다. 검색하면 영상 탭으로 바뀌고, 카테고리를 누르면 검색이 풀립니다.

### 계정 목록

화면에서 계정을 바꾸면 `app/` 에 아래 파일이 생깁니다. 백업하거나 옮길 때 함께 복사하세요.

| 탭 | 파일 |
|---|---|
| 릴스 | `reels_accounts.json` |
| X | `x_accounts.json` |
| 스레드 | `threads_accounts.json` |
| 틱톡 | `tiktok_accounts.json` |

### 데이터 출처와 한계

- 유튜브: 내부 검색 API(InnerTube)를 조회수순으로 부릅니다. 유튜브의 공개 인기 급상승 피드는 2025년에 없어져서 검색으로 구성했습니다.
- 릴스: instagram.com 웹이 쓰는 내부 API 를 로그인 없이 부릅니다. 계정당 최근 12개까지이고, 요청이 잦으면 인스타그램이 잠시 막을 수 있습니다. 썸네일은 서버 프록시(`/api/img`)로 전달합니다.
- X: 임베드 위젯용 syndication API 를 로그인 없이 부릅니다. 이 API 에는 조회수가 없어서 조회수순 정렬을 뺐습니다.
- 스레드: 지금은 기본으로 막혀 있어 계정 바로가기로 바뀝니다. `server.py` 의 `THREADS_DOC_IDS` 에 유효한 doc_id 를 넣으면 실시간 조회가 됩니다.
- 틱톡: 무료 공개 API tikwm(`www.tikwm.com/api`)을 거칩니다. 무료 등급이라 서버는 낮은 동시성(3)으로 부르고 1시간 캐시합니다.

### 알아둘 것

- 틱톡 요청(계정 핸들 · 조회 내역)은 제3자 서비스 tikwm.com 으로 갑니다. 그 서비스가 바뀌면 틱톡 탭이 언제든 멈출 수 있습니다.
- 모든 플랫폼 데이터는 비공식 · 무인증 내부 API 로 가져옵니다. 각 서비스 약관상 회색지대이고 예고 없이 막힐 수 있습니다. 개인 열람용으로만 쓰고, 지나친 새로고침은 피하세요.
- 이 팩의 `server.py` 에는 원본보다 보안 패치 2건이 더 들어 있습니다: 계정 변경 POST 의 Origin 검증, 이미지 프록시의 호스트 검사 강화.
