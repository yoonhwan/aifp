📱 Work from your phone

Your AI coding agents keep working on your Mac. Your phone is the window.

The work stays at home. You check in from anywhere.

Four pieces

🔗
TailscalePuts the phone and the Mac on one private network.
🚪
TermiusAn SSH app. The door from the phone into the Mac.
🧱
tmuxKeeps sessions alive after you disconnect.
👆
tmuxc + tmmtmuxc opens sessions. tmm picks one with your thumb.

A day with it

  1. 🖥️
    At the Mac: open a sessiontmuxc open ~/work/my-app --name my-app --agent claude
  2. 🚶
    Go outLeave the Mac on. The agents keep working inside tmux.
  3. 📱
    On the phone: type tmmOpen Termius, connect to the Mac, type tmm. The session that waits for you is on top.
  4. 💬
    Answer and put the phone awayPick it, send one line, done.

What is aifp?

AI Feature Pack is a box of small tools, called packs, for AI coding agents.

Take only the pack you need. Each one installs on its own.

Made for Claude Code · Codex · Pi · OpenCode · OpenClaw. tmuxc and tmm are two of the packs.

See all packs on GitHub →

Start

  1. Install Tailscale on the Mac and on the phone.
  2. Turn on Remote Login (SSH) on the Mac and install Termius on the phone.
  3. On the Mac, paste this into a terminal:
git clone https://github.com/yoonhwan/aifp.git && cd aifp \ && bash feature-pack/tmuxc/install.sh \ && bash feature-pack/tmm/install.sh

Needs macOS · bash 4+ · git · tmux · fzf (for tmm).
