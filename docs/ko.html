내 AI 에이전트를, 폰에서 씁니다

AI Feature Pack 은 코딩 에이전트를 쓰는 분을 위한 도구 묶음입니다. 필요한 것만 골라 설치하실 수 있습니다. 이 글은 그 가운데 «집 컴퓨터의 에이전트를 밖에서 폰으로 다루는 법» 을 먼저 안내해 드립니다.

한눈에 보기

쉬운 비유로 말씀드리면 — 집 컴퓨터는 사무실이고, AI 에이전트는 그 안에서 일하는 직원입니다. 직원마다 자기 책상(터미널 세션)이 있습니다.

폰은 그 사무실을 들여다보는 창문이자 인터폰입니다. 밖에 계셔도 직원들은 계속 일하고, 폰으로 «지금 누가 저를 기다리나» 를 보고, 한마디 건네고, 다시 주머니에 넣으시면 됩니다.

폰 화면에는 «누가 기다리는지» 가 맨 위에 오고, 고른 세션의 마지막 말이 아래에 보입니다.

원격으로 쓰는 법 — 짧게

  1. 기기를 한 네트워크로Tailscale 을 폰과 컴퓨터에 설치하시면 두 기기가 같은 사설 네트워크에 놓입니다. 공유기 설정을 건드리실 필요가 없습니다.
  2. 폰에서 SSH 로 접속Termius 같은 SSH 앱으로 컴퓨터에 들어갑니다. 키 인증을 쓰시기를 권해 드립니다.
  3. 세션은 tmux 가 지킵니다에이전트를 tmux 세션 안에서 띄워 두시면, 터미널을 닫거나 폰 연결이 끊겨도 세션은 그대로 살아 있습니다.
  4. 다시 붙기만 하시면 됩니다대화를 다시 불러오는 resume 이 필요 없습니다. 살아 있는 세션에 붙으면 하던 화면 그대로입니다.

여기까지가 바탕입니다. 다만 세션이 많아지면 폰에서 이름을 치고 찾는 일이 힘들어집니다. 아래 두 도구가 그 부분을 맡습니다.

tmuxc · tmm — 가장 먼저 권해 드리는 두 가지

이 묶음에서 가장 쓰기 편한 조합이라 먼저 권해 드립니다. tmuxc 로 세션을 열고, tmm 으로 폰에서 고릅니다.

컴퓨터에서 · 여는 도구

tmuxc

프로젝트 폴더나 git worktree 에 에이전트 세션을 한 줄로 엽니다. Claude Code · Codex CLI · OMX · OpenCode · Command Code · Pi 를 같은 명령으로 다룹니다.

  • 세션 열기 · 목록 · 정리
  • 붙지 않고 최근 출력 읽기
  • 세션에 메시지를 보내고 도착을 확인
  • 끄기 전 저장, 재부팅 뒤 복원
  • 대화를 다른 세션으로 갈라 이어 가기(fork)
폰에서 · 고르는 도구

tmm

수십 개의 세션(«좌석»)을 한 화면에서 커서로 고르는 TUI 입니다. 폰 키보드로 세션 이름을 치실 일이 없습니다.

  • 커서와 몇 글자 검색으로 좌석 고르기
  • 붙지 않고 미리보기(자동 갱신)
  • 고른 좌석에 메시지 보내기
  • 사람 입력을 기다리는 좌석을 맨 위로
  • 가장 최근에 말한 좌석 순으로 정렬

tmuxc — 자주 쓰는 명령

# 프로젝트 폴더에 에이전트 세션 열기 tmuxc open ~/work/my-app --name my-app --agent claude # 지금 열려 있는 세션 보기 tmuxc list # 붙지 않고 마지막 출력 40줄 읽기 tmuxc ask my-app 40 # 세션에 한마디 보내기 tmuxc send my-app "테스트 돌리고 결과만 알려 주세요" # 끄기 전에 전부 저장 → 재부팅 뒤 복원 tmuxc save tmuxc restore --go

tmm — 폰에서 보이는 화면

──────────────────────────────────────── tmm ── 이동 ⏎ 붙기 ^S 메시지 ^F fork ^X 끝 정렬 ^T 최근 ^W 대기 ^G 분류 ^H 대기만 좌석> 결제 1/24 ─────────────────────────────────────────────── ▶ 앱 ● 결제-수정 HUMAN 12:33 2m my-app 앱 ● 테스트 BUSY 12:52 6m my-app 문서 ● 안내문 BUSY 12:50 8m docs 조사 ● 자료-정리 IDLE 12:21 37m notes ──────────────────── 미리보기 ────────────────── ⏺ 변경 3건을 올렸습니다. 배포해도 될까요?

위 화면은 설명을 위한 예시입니다. HUMAN 은 사람의 답을 기다리는 좌석, BUSY 는 일하는 중, IDLE 은 쉬는 중이라는 뜻입니다.

키하는 일
↑↓ · 글자 입력커서 이동 · 몇 글자로 좌석 걸러 내기
Enter그 좌석에 붙기. 떼면 고르는 화면으로 돌아옵니다
^S붙지 않고 메시지 보내기. 보낸 뒤 도착했는지 확인합니다
^W · ^H기다리는 좌석을 위로 · 기다리는 좌석만 보기
^T · ^G최근에 말한 순 · 분류별 묶음
^P · ^O · ^U미리보기 켜고 끄기 · 크기 · 자동 갱신 간격
^D종료된 세션 보기 — 재부팅 뒤 되살릴 때 씁니다

tmm 은 tmuxc 로 연 세션을 전제로 만들었지만 보통 tmux 세션에도 그대로 쓰실 수 있습니다.

fable-team — 개념만

에이전트 한 명이 아니라 여럿을 팀으로 굴리고 싶을 때 쓰는 하네스입니다. 자세한 운영 방식은 리포 문서에 있고, 여기서는 생각의 뼈대만 말씀드립니다.

  • 역할을 나눕니다. 일을 쪼개고 나눠 주는 쪽, 계획을 세우는 쪽, 만드는 쪽, 검토하는 쪽이 서로 다른 세션입니다.
  • 일감은 파일 한 장입니다. 무엇을 하고 언제 끝난 것인지가 글로 적혀 있어, 세션이 바뀌어도 일은 이어집니다.
  • 세션끼리 쪽지를 주고받습니다. 보냈다고 끝내지 않고 도착을 확인합니다.
  • 사람이 정할 일은 사람에게 올립니다. 지우기 · 되돌릴 수 없는 일은 승인 없이 하지 않습니다.

tmuxc 와 tmm 이 익숙해지신 다음에 보시기를 권해 드립니다.

설치

리포: github.com/yoonhwan/aifp

tmuxc 와 tmm 을 한 줄로 설치하시려면 아래를 터미널에 붙여 넣으시면 됩니다.

git clone https://github.com/yoonhwan/aifp.git && cd aifp && bash feature-pack/tmuxc/install.sh && bash feature-pack/tmm/install.sh
  • 필요한 것: macOS · bash 4 이상 · git · tmux · fzf(tmm 용).
  • 에이전트에게 맡기셔도 됩니다. 리포를 받은 뒤 «feature-pack/tmm/INSTALL.md 읽고 설치해 주세요» 라고 말씀하시면 됩니다.
  • 다른 팩도 같은 꼴입니다. 팩 폴더의 README.md 와 INSTALL.md 에서 시작하시면 됩니다.

보안 점검

이 리포는 비공개 작업 리포에서 내보낸 사본입니다. 내보낼 때마다 파일 전체를 58종 패턴(키 · 토큰 · 주소 · 식별자)으로 검사하고, 검토한 허용 목록 밖에 남은 것이 없을 때만 내보냅니다.

0건 — 바로 쓸 수 있는 키 · 토큰 · 비밀번호 · 개인 키는 찾지 못했습니다.

  • 키 꼴로 보이는 글자는 있지만 모두 시험용 가짜 값이거나 설치 문서의 자리표시입니다.
  • 내부 기록과 식별자는 뺐습니다. 내부 운영 기록은 사본에 넣지 않았고, 개인 · 조직 식별자는 자리표시로 바꿨습니다.
  • 점검의 한계도 말씀드립니다. 전용 비밀 검색 도구가 아니라 패턴 검색으로 본 결과입니다.

설치하실 때에는 본인의 키와 토큰을 리포 폴더 안의 파일에 적지 않으시기를 권해 드립니다.
