📱 휴대폰에서 일하는 법

AI 코딩 에이전트는 맥에서 계속 일합니다. 휴대폰은 그 창입니다.

일은 집에서 계속됩니다. 어디서든 들여다보면 됩니다.

네 가지 조각

🔗
Tailscale휴대폰과 맥을 한 사설 네트워크에 놓습니다.
🚪
TermiusSSH 앱입니다. 휴대폰에서 맥으로 들어가는 문입니다.
🧱
tmux연결이 끊겨도 세션을 살려 둡니다.
👆
tmuxc + tmmtmuxc 로 세션을 엽니다. tmm 으로 엄지로 고릅니다.

하루는 이렇게

  1. 🖥️
    맥에서: 세션을 엽니다tmuxc open ~/work/my-app --name my-app --agent claude
  2. 🚶
    밖으로 나갑니다맥은 켜 둡니다. 에이전트는 tmux 안에서 계속 일합니다.
  3. 📱
    휴대폰에서: tmm 을 칩니다Termius 를 열고 맥에 접속해 tmm 을 칩니다. 나를 기다리는 세션이 맨 위에 옵니다.
  4. 💬
    답하고 휴대폰을 넣습니다고르고, 한 줄 보내면 끝입니다.
seat> 1/4 ▶ ● pay-fix HUMAN 2m ● tests BUSY 6m ● guide BUSY 8m ● notes IDLE 37m ────────────────────────────────── ⏺ 변경 3건을 올렸습니다. 배포해도 될까요?

tmm 화면 예시입니다. HUMAN = 나를 기다림 · BUSY = 일하는 중 · IDLE = 쉬는 중.

시작하기

  1. 맥과 휴대폰에 Tailscale 을 설치합니다.
  2. 맥에서 원격 로그인(SSH)을 켜고, 휴대폰에 Termius 를 설치합니다.
  3. 맥 터미널에 아래를 붙여 넣습니다:
git clone https://github.com/yoonhwan/aifp.git && cd aifp \ && bash feature-pack/tmuxc/install.sh \ && bash feature-pack/tmm/install.sh

필요한 것: macOS · bash 4 이상 · git · tmux · fzf(tmm 용).

AI Feature Pack · 화면과 이름은 설명을 위한 예시입니다.
